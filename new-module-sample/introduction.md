# CS120: Programming Fundamentals

CS120 introduces programming as a way to express precise, reusable problem-solving steps. The course begins with values and expressions, then moves through conditionals, loops, functions, and collections.

## Learning goals

By the end of this introductory unit, you should be able to:

- evaluate and combine Python expressions;
- store values in variables;
- define and call a function;
- use lists and dictionaries to organize information; and
- test a small program with several inputs.
