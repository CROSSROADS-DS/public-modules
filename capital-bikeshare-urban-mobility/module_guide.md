# Capital Bikeshare: Urban Mobility Across Space and Time

## Module overview

How can trip data help a bikeshare program better understand its service and serve the community? In this introductory module, students take the role of analysts working with Capital Bikeshare trip data from Washington, DC.

Students begin by developing questions that could be useful to the organization. They then evaluate the available data, refine their questions, and follow a shared investigation of where and when bikeshare trips occur. The activity emphasizes evidence-based reasoning, cautious interpretation, and the idea that limited or unexpected findings can still be informative.

## Intended audience

This module is designed for introductory college courses in data science, geography, urban studies, transportation, environmental studies, sociology, economics, public policy, business, and general education. It can also serve as an approachable early activity in a programming or statistics course.

No prior programming experience is required. Students run and adjust short helper-function calls while focusing on questions, evidence, and interpretation. Students with more experience may inspect or extend the Python code.

## Learning goals

By the end of the module, students should be able to:

- formulate and refine questions that can be investigated with available data;
- use spatial and temporal evidence to describe patterns in bikeshare activity;
- distinguish observations from interpretations and service implications;
- identify important limitations of a prepared dataset;
- use simple helper functions to continue an independent investigation; and
- explain how data science can support decisions about an urban transportation service.

## Data

The activity uses a prepared sample of Capital Bikeshare trips from January, April, July, and October 2025. The smaller dataset was designed for learning, interpretability, and reliable browser-based use. A separate landmark file provides recognizable Washington, DC locations for geographic orientation.

The module briefly explains how the sample was created and shows an example comparison with the original data. Because the four months contain different sample sizes, raw monthly totals should not be used to infer actual seasonal ridership.

## Classroom use

The guided investigation is designed for approximately **60 minutes**. Instructors may add the optional clustering activity or the rider-type exploration for a 75–90 minute session, homework, or follow-up assignment.

The notebook is modular. Instructors may use the shared investigation alone, assign the independent exploration, or select individual spatial and temporal sections for a shorter class.

## Software

The activity is provided as a Python notebook designed to run in Jupyter or JupyterLite. Students use the included `tool_library.py`; no software installation or substantial coding is required when the notebook is launched through the CROSSROADS Hub.
