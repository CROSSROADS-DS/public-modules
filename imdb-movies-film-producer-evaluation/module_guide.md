# Movies - Investigating Patterns, Types of Data, and Distribution of Data

## Module overview

How do movie producers use data in a creative industry? In this module, students act as **film producers** identifying trends in order to **pitch a movie** to be made by a major studio. 

Students begin by developing questions that could be useful to their job. They then evaluate the available data, refine their questions, and follow a shared investigation of film genres. The activity emphasizes reasoning and interpretation of patterns.

## Intended audience

This module is designed for introductory college courses in data science, film studies, business, marketting, economics, and general education. It can also serve as an approachable early activity in a programming or statistics course.

No prior programming experience is required. Students run and adjust short helper-function calls while focusing on questions, evidence, and interpretation. Students with more experience may inspect or extend the Python code.

## Learning goals

By the end of the module, students should be able to:

- Understand different types of data, such as categorical; textual; numerical; and time-series
- Create and investigate self-directed questions
- Explain interpretations of data using specific details
- Recognize limitations or issues in the data 
- Chart two different properties in order to use them to predict future values

## Data

The activity uses a sample of movies from IMDB between 1980 and 2019. This dataset was chosen for learning, and is cleaned up slightly for students' use. The module briefly explains how the sample was found and cleaned.

## Classroom use

The shared investigation is designed for approximately **60 minutes**. Instructors may add the optional independent investigation for a 75–90 minute session, homework, or follow-up assignment.

The notebook is modular. Instructors may use the shared investigation alone, assign the independent exploration, or select sections for a shorter class.

## Software

The activity is provided as a Python notebook designed to run in Jupyter or JupyterLite. Students use the included `tool_library.py`; no software installation or substantial coding is required when the notebook is launched through the CROSSROADS Hub.
